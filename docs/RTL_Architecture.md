# RTL Architecture and Implementation

## 1. Top-Level Organization

The synthesizable top-level module is `top_interpolator_dac`. It implements two parallel fixed-point datapaths, one for I and one for Q, together with common configuration and timing control.

```text
top_interpolator_dac
|
+-- spi_cfg4_nomode
|
+-- spi_i_master
+-- spi_q_slave
|
+-- word_history3                     [I]
+-- word_history3                     [Q]
|
+-- minaj2_interp_3samp_internalSlope [I]
+-- minaj2_interp_3samp_internalSlope [Q]
|
+-- minaj2_window_latch               [I]
+-- minaj2_window_latch               [Q]
|
+-- sample_shift_ntaps_I
+-- sample_shift_ntaps_Q
|
+-- fir20_q16_fromx                   [I]
+-- fir20_q16_fromx                   [Q]
```

Main parameters are:

| Parameter | Value | Purpose |
|---|---:|---|
| `WL` | 16 | Signal word length |
| `FL` | 12 | Fractional length |
| `NTAPS` | 10 | FIR tap count |

All sequential logic is driven by the external `clk`. Multi-rate behavior is implemented using enables and strobes rather than internally generated clocks.

## 2. Operating Modes

| L | External Clock | Normal Input Word | Input Rate | Output Rate |
|---:|---:|---:|---:|---:|
| 2 | 960 MHz | 16 bits | 60 MSa/s | 120 MSa/s |
| 3 | 900 MHz | 15 bits | 60 MSa/s | 180 MSa/s |
| 4 | 960 MHz | 16 bits | 60 MSa/s | 240 MSa/s |
| 5 | 900 MHz | 15 bits | 60 MSa/s | 300 MSa/s |

For odd \(L\), bit 14 is the serial input sign bit and the received 15-bit word is sign-extended to 16 bits before entering the datapath.

## 3. Startup and Configuration

The I serial input carries configuration before normal data streaming.

```text
reset
  |
  v
detect synchronization marker = 1
  |
  v
capture L[0], L[1], L[2]
  |
  v
en_stream = 1
  |
  v
load 10 signed 16-bit FIR coefficients
  |
  v
coeff_done = 1
  |
  v
enable normal I/Q processing
```

The top-level control separates coefficient loading from normal streaming:

```text
coeff_load_mode = en_stream && !coeff_done
en_iq           = en_stream &&  coeff_done
```

This prevents configuration words from entering the sample history and interpolation datapath.

## 4. FIR Coefficient Loading

All ten FIR coefficients are received through `serial_in_I`. The same completed coefficient word is provided to both FIR instances, so I and Q always use the same coefficient set.

Coefficients are always 16-bit words, including in \(L=3\) and \(L=5\), where normal I/Q samples are 15 bits. During coefficient loading the I serial master is therefore forced into 16-bit word mode.

After the tenth coefficient word, `coeff_done` remains asserted and normal I/Q streaming begins.

## 5. I Master and Q Slave

`spi_i_master` reconstructs the I sample and owns the common timing decisions. It determines:

- 15- or 16-bit word mode,
- the raw completed-word pulse,
- the raw output-rate shift pulse.

`spi_q_slave` reconstructs Q using the word mode selected by the I path. It does not make an independent timing decision.

This master/slave structure keeps I and Q aligned at every word boundary.

## 6. Strobe Architecture

The principal strobes are:

| Signal | Function |
|---|---|
| `strobe_common` | Raw completed-word event generated by I master |
| `strobe_iq` | Normal aligned input-sample event after `coeff_done` |
| `shift_strobe_common` | Raw interpolation/output scheduling event |
| `shift_strobe_iq` | Normal output scheduling event after `coeff_done` |

Normal input words complete every 16 clocks for \(L=2,4\) and every 15 clocks for \(L=3,5\).

The output scheduler uses:

| L | Clock | Shift Interval | Output Rate |
|---:|---:|---:|---:|
| 2 | 960 MHz | 8 clocks | 120 MSa/s |
| 3 | 900 MHz | 5 clocks | 180 MSa/s |
| 4 | 960 MHz | 4 clocks | 240 MSa/s |
| 5 | 900 MHz | 3 clocks | 300 MSa/s |

## 7. Three-Sample History

`word_history3` stores the three samples required by MINAJ2:

```text
w0 = newest sample
w1 = current center sample
w2 = previous sample
```

On each `strobe_iq`:

```text
w2 <- w1
w1 <- w0
w0 <- new sample
```

Between input strobes, the history state is held.

## 8. MINAJ2 Core

The interpolation engine uses the previous slope \(m_p\) and three input samples:

```text
x_prev = w2
x_c    = w1
x_n    = w0
```

The slope numerator is

\[
Sum=8x_c+3x_n-11x_{prev}-4m_p.
\]

Division by ten is approximated in integer arithmetic by

\[
m_{new}=\mathrm{sat}_{16}\left((Sum\cdot1638+8192)\gg14\right).
\]

The cubic coefficients are

\[
c_0=x_{prev}
\]

\[
c_1=m_p
\]

\[
c_2=3(x_c-x_{prev})-2m_p-m_{new}
\]

\[
c_3=m_p+m_{new}-2(x_c-x_{prev}).
\]

The normalized interpolation phase \(u\) is represented in Q1.15 and the polynomial is evaluated in Horner form to reduce hardware cost.

The implemented Q1.15 phase constants include the required fractions for all \(L=2..5\), such as \(1/2=16384\), \(1/3=10923\), \(1/4=8192\), and \(1/5=6554\).

## 9. Interpolation Window and Sample Scheduling

`minaj2_window_latch` captures the interpolation group generated for the current input interval. The Sample Shift blocks then select the appropriate point at each `shift_strobe_iq`.

The I Sample Shift owns the phase counter and exports the shared phase. The Q Sample Shift follows this phase, guaranteeing aligned I/Q sample selection.

When an input-word event and output-shift event occur together, the input strobe has priority. This ensures that every newly generated interpolation group restarts at phase zero.

## 10. Programmable 10-Tap FIR

Each channel contains one `fir20_q16_fromx` instance configured for ten taps.

The FIR:

- stores ten runtime-loaded coefficients,
- advances only on a valid interpolated sample event,
- performs the signed multiply-accumulate operation in a wider accumulator,
- rescales by `FL=12`,
- saturates the result to the 16-bit output range.

The bit-accurate MATLAB regression uses the same state-update order and scaling behavior.

## 11. Fixed-Point Summary

| Quantity | Format / Width |
|---|---|
| Input / output signal | Signed 16-bit, 12 fractional bits |
| Odd-mode serial input | Signed 15-bit, sign-extended to 16 |
| FIR coefficient | Signed 16-bit, 12 fractional bits |
| MINAJ2 phase \(u\) | Q1.15 |
| FIR accumulator | Wider internal accumulator (48-bit RTL MAC) |
| Final output | Signed 16-bit with saturation |

## 12. End-to-End Operation

```text
Reset
  |
  v
Capture L
  |
  v
Load 10 FIR coefficients
  |
  v
Receive aligned serial I/Q words
  |
  v
Update three-sample histories
  |
  v
Compute MINAJ2 interpolation group
  |
  v
Latch interpolation window
  |
  v
Schedule L output samples
  |
  v
Filter I and Q with programmable FIRs
  |
  v
dac_I / dac_Q
```
