# System Architecture

## 1. System Goal

The chip performs real-time sample-rate interpolation of complex baseband I/Q data. The input stream is sampled at 60 MSa/s and the interpolation factor is programmable:

$$
L \in \{2,3,4,5\}
$$

The output sample rate is therefore

$$
f_{out}=L\cdot f_{in}
$$

with

$$
f_{in}=60\ \text{MSa/s}.
$$

This gives output rates of 120, 180, 240, and 300 MSa/s.

The processing chain is:

```text
Serial I/Q Input
      |
      v
Serial-to-Parallel Reception
      |
      v
Three-Sample History
      |
      v
MINAJ2 Cubic Interpolation
      |
      v
Interpolation Window
      |
      v
Sample Scheduling
      |
      v
Programmable 10-Tap FIR
      |
      v
I_out / Q_out
```

## 2. Clock and Input-Word Strategy

The chip does not internally choose between the two external clocks. The correct clock is supplied from outside according to the selected interpolation mode.

| L | External Clock | Normal I/Q Word | Input Sample Rate |
|---:|---:|---:|---:|
| 2 | 960 MHz | 16 bits | 60 MSa/s |
| 3 | 900 MHz | 15 bits | 60 MSa/s |
| 4 | 960 MHz | 16 bits | 60 MSa/s |
| 5 | 900 MHz | 15 bits | 60 MSa/s |

For \(L=3\) and \(L=5\), bit 14 is the sign bit of the received 15-bit sample. It is sign-extended internally to the common 16-bit datapath width.

This clock/word pairing keeps the source-sample rate equal to 60 MSa/s for every mode.

## 3. I-Master / Q-Slave Organization

The two numerical datapaths are parallel, but their timing control is intentionally asymmetric.

- **I path - Master:** generates the common serial word timing, decides whether the normal input word is 15 or 16 bits, generates input/output strobes, and owns the interpolation phase counter.
- **Q path - Slave:** reconstructs the Q serial word using the mode and phase information generated by the I path.

This organization guarantees that an I sample and its corresponding Q sample finish on the same clock edge and that both channels always select the same interpolated point.

## 4. Configuration Sequence

After reset, the chip first receives configuration through `serial_in_I`.

```text
Reset
  |
  v
Wait for synchronization bit = 1
  |
  v
Capture three bits of L
  |
  v
Assert en_stream
  |
  v
Load 10 FIR coefficients through serial_in_I
  |
  v
Assert coeff_done
  |
  v
Enable normal I/Q streaming
```

The interpolation factor determines:

- the interpolation ratio;
- the normal serial input word length;
- the interpolated output rate;
- the number of valid output phases in each interpolation window.

## 5. FIR Coefficient Loading

After \(L\) has been captured,

```text
en_stream = 1
coeff_done = 0
```

so the top level enters coefficient-loading mode:

```text
coeff_load_mode = en_stream && !coeff_done
```

All FIR coefficients are signed 16-bit words and enter through `serial_in_I`. Each completed coefficient is reconstructed as `word_I` and loaded into both the I and Q FIRs.

After ten coefficients have been received:

```text
coeff_done = 1
coeff_load_mode = 0
en_iq = 1
```

Normal I/Q processing then starts automatically.

## 6. Multi-Rate Data Movement

The design uses one external high-frequency clock domain. Lower-rate operations are enabled by strobes.

Two rates are fundamental:

- **60 MHz:** a new source I/Q sample pair is accepted.
- **\(60L\) MHz:** one interpolated point is selected and passed into each FIR.

For \(L=5\), the FIR input/output activity reaches 300 MHz.

A new interpolation window is computed once for each 60 MHz input pair. The stored points are then consumed one by one at \(60L\) MHz.

## 7. MINAJ2 and FIR Roles

MINAJ2 is a local cubic Hermite interpolation method. It uses three neighboring samples and a recursively updated slope estimate to generate up to five points for the current interval.

The 10-tap FIR follows the interpolator to suppress interpolation images and improve the final signal quality. The coefficient set is programmable and can therefore be optimized separately for each interpolation factor without changing the RTL architecture.

## 8. Fixed-Point Representation

| Quantity | Representation |
|---|---|
| Main signal datapath | Signed 16-bit |
| Main fractional length | 12 bits |
| Odd-mode external input | Signed 15-bit, sign-extended to 16 |
| FIR coefficients | Signed 16-bit, Q12 |
| Interpolation phase \(u\) | Q1.15 |
| FIR accumulator | Wider internal accumulator |
| Final I/Q output | Signed 16-bit with saturation |
